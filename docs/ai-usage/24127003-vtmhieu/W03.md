* **Tóm tắt kết quả AI sinh ra:**
  - Phân tích rủi ro over-engineering trong 3 tuần code ở PA5.
  - Thiết kế kiến trúc Pragmatic Microservices chạy cục bộ qua Docker Compose: 1 Nginx API Gateway + 3 Core Services (`auth-service`, `academic-service`, `student-affairs-service`) + 1 Notification Worker.

  - Đề xuất kiến trúc Email Service bất đồng bộ dùng Go Buffered Channel và Goroutine Worker Pool kết nối Resend API / Gmail SMTP.
  - Sinh toàn bộ file tài liệu đặc tả kiến trúc: `docs/design/system-architecture-spec.md`.
