# AI Usage Logs

This directory stores logs of AI-assisted contributions (architectural design, code generation, refactoring, and testing) for the **Portal67** project, adhering to HCMUS academic guidelines.

## Guidelines
* Team members record their significant AI interactions here when using generative AI tools (Copilot, Claude, ChatGPT, Gemini, Antigravity, etc.).
* Each log should be created and maintained by the individual member when performing work.
* Use [`TEMPLATE.md`](TEMPLATE.md) as a starting reference for log structure.
